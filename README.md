# Random Quote Generator

This project is a simple **Random Quote Generator** built using HTML, CSS, and JavaScript. It fetches random quotes from a JSON file and displays them dynamically on the webpage.

## Features

### 1. Random Quote Display
- Fetches quotes from a local `quotes.json` file.
- Displays a random quote along with its author on the webpage.
- Automatically loads a random quote when the page is first opened.

### 2. New Quote Button
- A **"New Quote"** button allows users to fetch and display a new random quote.

### 3. Responsive Design
- The layout is styled using CSS to ensure a visually appealing and responsive design.
- The design adapts to different screen sizes and maintains usability on both desktop and mobile devices.

### 4. Styled Buttons
- Buttons are styled with hover effects, including smooth transitions and shadows for better user interaction.

### 5. Quote Styling
- Quotes are displayed in a bold and visually distinct format.
- Authors are displayed in a smaller, lighter font for contrast.

## File Structure
- **index.html**: The main HTML file containing the structure of the webpage.
- **style.css**: The CSS file for styling the webpage.
- **script.js**: The JavaScript file for fetching and displaying quotes dynamically.
- **quotes.json**: A JSON file containing a collection of quotes and their authors.

## How to Use
1. Open the `index.html` file in a browser.
2. Click the **"New Quote"** button to fetch and display a new random quote.
